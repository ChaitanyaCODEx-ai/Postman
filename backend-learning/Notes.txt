* What is Flask?
Flask is a Python web framework that allows developers to build web applications quickly and easily. 
It is lightweight, flexible, and easy to use, making it a popular choice for building web applications 
in Python. Flask provides tools and libraries for routing, templating, and handling HTTP requests and 
responses, allowing developers to focus on writing application logic rather than dealing with low-level
details.
* ------------------------------------------------------------------------------------------------------------ *
* Explain the 5 HTTP methods
GET: give me the data.
POST: create new data.
PUT: update existing data.
PATCH: partially update existing data.
DELETE: remove data

* What is __name__?
In Python, __name__ is a special built-in variable that represents the name of the current module. 
When a Python script is run directly, the value of __name__ is set to "__main__". However, when a 
script is imported as a module in another script, the value of __name__ is set to the name of that 
module.
It's a special Python variable that tells us the name of the current module. Flask uses it to identify 
the application and locate resources such as templates and static files.

* @app.route("/")
The @ symbol introduces a Python decorator.
A decorator modifies or extends the behaviour of a function. Flask uses this decorator to register the 
URL route.
For example:
* URL	        Function
/	            home()
/students	    students()
/courses	    courses()

home() is still a normal Python function. Flask automatically calls it when a user visits the URL 
mapped to it using @app.route("/")

LEVEL 3 -  Dynamic Routes
Dynamic routes allow us to create URLs that accept changing values. Flask extracts those values from the URL and 
passes them as arguments to the corresponding Python function.
@app.route("/students/<int:student_id>")

*   Route syntax	Accepted value
    <int:id>	    Integer
    <string:name>	String (default)
    <float:price>	Decimal number
    <path:location>	String that can include /

Level 5 - JSON & API Responses
JSON (JavaScript Object Notation) is a format used to store and exchange data between applications.
The dictionary is a Python data structure. JSON is a data-exchange format.

jsonify() converts Python data into a JSON HTTP response. Flask also sets the appropriate response 
content type.

@app.route("/students")
def students():
    students = [
    {"name": "Aman", "age": 21},
    {"name": "Rahul", "age": 20},
    {"name": "Priya", "age": 22}
]
    return jsonify(students)

JSON can represent both objects (like dictionaries) and arrays (like lists).
1. JSON Object
{
    "name": "Aman",
    "age": 21
}
2. JSON Array
[
    "Aman",
    "Rahul",
    "Priya"
]
[
    {"name": "Aman", "age": 21},
    {"name": "Rahul", "age": 20}
]

THIS IS AN OBJECT
{
    "students": [
        {"name": "Aman"},
        {"name": "Rahul"}
    ],
    "total": 2
}
The entire response starts with { → Object.
"students" contains an Array [ ].
Each student inside the array is an Object { }.
"total" is a number.

Level 6 - POST Requests & Data Submission
This is where we'll move from simply retrieving data to actually sending data to our backend
* GET	                                POST
Retrieves data	                        Submits data
Usually sends parameters in URL	        Usually sends data in request body
Used to read information	            Commonly used to create resources
POST data is not automatically secure. HTTPS is still necessary to protect data in transit.

- URL tells the server which endpoint to contact.
- Request body carries the data we want to submit.

Remember, frontend sends JSON in the request body. Flask needs to read that data.
We use:
request.get_json() -----> This reads the JSON request body and converts it into a Python dictionary.

@app.route("/register") ---> accepts GET requests by default
@app.route("/register", methods=["POST"]) -----> To accept POST requests

/register is the endpoint.
methods=["POST"] tells Flask to accept POST requests on this endpoint

STUDY THE CODE
@app.route("/register", methods=["POST"])
def register():
    data = request.get_json()

    return jsonify({
        "message": "Student registered successfully",
        "name": data["name"],
        "age": data["age"]
    })

1. Frontend sends a POST request to /register.
2. request.get_json() reads the submitted JSON.
3. data["name"] retrieves the student's name.
4. data["age"] retrieves the student's age.
5. jsonify() sends the response as JSON

request.get_json() receives the JSON body.
data.get("name") extracts the student's name.
if name: checks whether a name was provided.
